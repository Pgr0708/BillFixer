Fonts

Screens use Figtree, Outfit, Plus Jakarta Sans, DM Sans, Lora and JetBrains Mono. Figma substitutes any face it can't find, so install them (all are free on Google Fonts) before pasting if you want the type to land exactly as drawn.

Colors and shadows match the 63 published styles already in the Figma file, so pasted screens sit on the same system as screens 01–09.
